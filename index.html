Линейная функция

y = kx + b

  • k — угловой коэффициент
  • k > 0 угол острый
  • k < 0 угол тупой
  • b — точка пересечения с осью Y

графиком является прямая

Попробуй сам

y = x + 2

Обратная пропорциональность

y = kx

  • k > 0 — ветви в I и III четвертях
  • k < 0 — ветви во II и IV четвертях

графиком является гипербола

Попробуй сам

y = kx + m + n

та же гипербола, сдвинутая по осям

  • асимптоты: x = −m и y = n
  • m > 0 — сдвиг влево на m
  • m < 0 — сдвиг вправо на |m|
  • n > 0 — сдвиг вверх на n
  • n < 0 — сдвиг вниз на |n|
  • k — как и раньше: четверти и размах ветвей
